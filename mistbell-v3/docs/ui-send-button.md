# 发送按钮 · 美术与动效需求（交给绘图 / 动效 AI）

## 0. 一句话目标

把现在那颗"静态紫色圆 + 纸飞机图标"的发送键，换成**有呼吸感、有反馈、有一点科幻感**的按钮；它要能表达四个状态：待机、按下、发送中、生成中（可停止）。

---

## 1. 硬性约束（先看这个，避免白做）

| 项 | 要求 |
| --- | --- |
| 承载端 | Android Jetpack Compose，**离线包内含资源，不联网** |
| 逻辑尺寸 | **56 × 56 dp**（红米 K70 Pro 上 = 196 × 196 px @3.5x） |
| 导出尺寸 | 交付 **192 × 192 px** 起，或 Lottie 矢量（无限缩放） |
| 格式 | **首选 Lottie `.json`**；备选 PNG-32 序列帧；纯静态就 3 张 PNG |
| 背景 | 按钮会叠在暗紫酒馆背景上，**必须透明底**，带一圈外发光 |
| 禁止 | 写实金属、3D 渲染风、彩色渐变过多、自带文字、自带白底 |

---

## 2. 视觉规格

- **底**：圆形，主渐变 `#8B5CF6 → #5B21B6`，角度 135°（左上亮、右下暗）
- **外发光**：半径外扩 8–12 px，颜色 `#9B6BFF`，不透明度 35%–55%，向边缘衰减到 0
- **内高光**：顶部内缘一条 1.5 px 的白色 18% 弧线，模拟玻璃边缘
- **描边**：1 px `#FFFFFF` 20%
- **图标**：纸飞机 / 箭头，线宽 2 px，颜色纯白；**图标不超过圆直径的 42%**
- **"科幻感"的落点**：靠**外发光呼吸** + **一圈极细的环形高光**（静止时 20% 不透明，激活时沿圆环走一圈），不要靠堆粒子

---

## 3. 状态与动效参数（这是重点）

| 状态 | 触发 | 表现 | 时长 / 曲线 |
| --- | --- | --- | --- |
| **待机 idle** | 输入框为空 | 外发光 35% ↔ 55% 缓慢呼吸；圆环高光静止 | 2400 ms，ease-in-out，无限循环 |
| **可发送 ready** | 输入框非空 | 亮度整体 +10%，发光扩到 65%，图标轻微上浮 1 dp | 180 ms，ease-out |
| **按下 pressed** | 手指按下 | 整体缩到 0.92，发光收紧，内高光变亮 | 90 ms 按下 / 140 ms 回弹（spring，damping 0.6） |
| **发送中 sending** | 点按后等待首 token | 图标淡出（120 ms）→ 出现一段 270° 的旋转弧线（2 px，#FFFFFF 90%，开口 90°），每圈 800 ms 匀速旋转；外发光跟着转速脉动 | 循环直到状态结束 |
| **生成中 streaming** | 正在输出 | 纸飞机**变形为停止方块**（圆角 4 px，边长 16 px），方块以 1600 ms 节奏轻度脉动（1.0 ↔ 0.88） | 循环 |
| **禁用 disabled** | 无法发送 | 整体不透明度 40%，去掉发光，不响应按压 | 静态 |

**关键细节**：从"发送中"回到"待机"时不要直接跳，用 200 ms 交叉淡入，否则会有闪烁感。

---

## 4. 交付清单（三选一，推荐 A）

### A. Lottie（首选）
一个文件里做 3 个 segment，或交 3 个文件：

```
send_idle.json      0–2400 ms 循环      （待机呼吸）
send_sending.json   0–800 ms 循环       （旋转弧线）
send_streaming.json 0–1600 ms 循环      （停止方块脉动）
```

要求：30 fps、体积 ≤ 60 KB/个、`fill` 用上述色值、`matte` 不要用（部分设备不兼容）。

### B. PNG 序列帧
- `send_idle_000.png … send_idle_023.png`（24 帧，24 fps，192×192，透明）
- 发送中 24 帧、生成中 24 帧，命名同理

### C. 静态三张
- `btn_send_idle.png` / `btn_send_pressed.png` / `btn_send_streaming.png`，192×192 透明。
- 拿这个我**用代码补动画**（呼吸、按压缩放、旋转弧、方块脉动都能纯 Compose 做），效果会比 Lottie 更轻、更能跟着真实请求状态走。

---

## 5. 验收标准

- [ ] 192×192（或 Lottie 矢量），四周留 12 px 透明给发光
- [ ] 叠在 `#0B0710` 深紫底上，发光边缘**不出现灰边/白边**
- [ ] 图标线宽在 192 尺寸下是 2 px（放大到 56 dp 后仍清晰）
- [ ] 三个循环动画首尾帧能无缝衔接
- [ ] 不发散、不出现纯白大面积（会盖过聊天正文）

---

## 6. 落地方式

文件放 `mistbell-v3/app/src/main/res/raw/`（Lottie）或 `res/drawable-nodpi/`（PNG），
我这边替换现在 `ChatMessageComposerInput` 右侧那颗按钮即可，不动布局。
