## 1. 通用规范（所有图都要遵守）

1. **格式**：PNG-24（不透明背景）或 PNG-32（需要透明的图）。
2. **色彩空间**：sRGB，不要 CMYK、不要嵌入 ICC。
3. **风格基调**：日系二次元（anime / visual novel 背景），赛璐璐 + 厚涂混合，**暗紫夜空酒馆**。
4. **禁止项**（出现即退回重出）：
   - 任何文字、字母、数字、logo、水印、签名、边框
   - UI 元素（按钮、卡片、图标、进度条、玻璃拟态面板）
   - 人物特写/人脸大特写（P0 背景里人物只允许虚化剪影或完全没有）
   - 高饱和荧光色、纯黑压死（#000 纯黑大面积会显得脏）、纯白高光块
5. **可读性铁律**：背景是给文字当底的。**画面正中间竖向 60% 区域必须低对比、低细节**，绝对不要在中间放亮部、大光斑、细密花纹或高反差线条；细节都往四周和底部放。
6. **安全区**（全屏图通用）：
   - 顶部 0–400 px：会被状态栏和标题栏压住，只放氛围，不放重要内容
   - 底部 2600–3200 px：会被输入框/底栏压住，必须做**加深渐变**（向下 alpha 递增到接近不透明的黑紫）
7. **文件名全小写 + 下划线**，不要中文名、不要空格、不要版本号。

### 风格锚点（每次出图都带上这段）

> 日系视觉小说背景，二次元赛璐璐上色，夜间酒馆，紫罗兰与靛蓝主调，烛光暖金点缀（#FFCE8A），雾气与丁达尔光，画面安静、有一点寂寞感，低对比、无人物、无文字、无 UI，高细节但暗部丰富。

### 负面锚点

> text, letters, watermark, signature, logo, UI, buttons, frame, border, photorealistic, 3d render, western cartoon, oversaturated, neon, pure black, pure white, blurry mess, distorted perspective, anime girl close-up face, chibi

## 2. P0 · 四张全屏背景（必须）

### 2.1 `bg_tavern.png` — 聊天页背景（最重要）

- **画布**：1440 × 3200 px
- **内容**：夜晚酒馆内景的一角。木质吧台/书架在左侧虚化，右侧是拱形窗或彩绘玻璃，窗外是紫夜与月亮；桌面有几盏蜡烛形成暖金光斑，空气里有细尘与薄雾。
- **构图**：
  - 主体结构压在**左 30%** 与**右 25%**两条竖带上，中间留空当"空气"
  - 蜡烛光斑高度控制在画面 55%–75% 区域，**不要放在正中**
  - 顶部 0–500 px 放一点穹顶/吊灯剪影，压暗
  - 底部 2600–3200 px 加深到接近 #0B0710 的 85% 不透明
- **整体明度**：偏暗，平均亮度目标 **20–30/255**（当前旧图是 24，可以更暗一点但别更亮）
- **调色**：主色 #2A1B3D / #150C22，高光 #FFCE8A，冷光 #9B6BFF
- **特别要求**：**不要画角色立绘**。立绘由角色卡自己带上来，背景画了人会和立绘打架。

### 2.2 `bg_sessions.png` — 会话列表背景

- **画布**：1440 × 3200 px
- **内容**：从酒馆门口向外看出去的雨夜街景，或者酒馆二层回廊俯视。灯笼、湿润石板路反光、远处城镇灯火。
- **构图**：视觉重心放**上半部**（400–1400 px），因为下半部要铺会话卡片；下半部做成"雾气逐渐变浓、细节消失"的效果。
- **明度**：比 `bg_tavern` 再暗一档，平均亮度 16–24/255，让卡片轮廓跳出来。
- **可以让**画面右上角有一点点月牙或教堂尖顶剪影增加辨识度，但不要抢标题。

### 2.3 `bg_settings.png` — 设置页背景

- **画布**：1440 × 3200 px
- **内容**：酒馆书桌特写：摊开的羊皮纸、羽毛笔、墨水瓶、燃烧的蜡烛、压着书页的怀表/星象仪。
- **构图**：书桌平面用大块暗面（好压字），道具集中在**画面下方 40%**和**左右边缘**；中间不要放密集文字状纹理（羊皮纸上的"字"必须画成模糊线条，绝不能像真字）。
- **明度**：平均 18–26/255。

### 2.4 `bg_memory.png` — 会话记忆页背景

- **画布**：1440 × 3200 px
- **内容**：记忆水晶/漂浮的星轨卡片/半透明记忆碎片在暗紫空间里缓慢飘动，背景有很淡的星座连线。
- **构图**：碎片全部集中在四角与上下边缘，中间大片虚空（记忆条目要在这里排）。
- **特色要求**：这张可以有少量**发光粒子**，但整体亮度仍然要暗（平均 ≤ 28/255），发光点直径 ≤ 6 px。
